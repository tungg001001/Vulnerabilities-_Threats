資安漏洞（Vulnerability）與威脅（Threat）核心概念

徹底拆解資安架構、評分標準（CVSS）、Top 10 漏洞與 MITRE ATT&CK 威脅戰術。

漏洞 (Vulnerability) —— 防禦上的弱點

定義：系統、軟體程式碼、網路協定、設定或管理流程中存在的**缺陷與弱點**。漏洞本身不會主動發起攻擊，但它提供了威脅侵入的門檻。

常見例子：
• 未修補的軟體缺陷（如 Log4j, Buffer Overflow）
• 系統設定不當（如使用預設密碼、未關閉閒置 Port）
• 人員意識弱點（未啟用 MFA、容易相信釣魚信件）

威脅 (Threat) —— 潛在的破壞力量

定義：任何可能利用漏洞對企業資產（資料、系統、業務運行）造成**傷害、破壞或中斷的潛在事件或行為者**。

常見例子：
• 人為意圖攻擊：黑客集團、APT 國家級網軍、不懷好意的內部員工
• 惡意程式：勒索軟體 (Ransomware)、DDoS 阻斷服務攻擊
• 環境與自然因素：地震、機房火災、電力供應中斷

資安核心風險公式 (Security Risk Formula)

$$\text{風險 (Risk)} = \text{威脅 (Threat)} \times \text{漏洞 (Vulnerability)} \times \text{資產價值 (Asset Value)}$$

當外部威脅（如駭客）成功利用了內部漏洞（如未修補的缺陷），且該目標具有重大價值時，就會演變為資安風險與嚴重的安全事件（Incident）。

CVSS 漏洞評分標準 (Common Vulnerability Scoring System)

CVSS 為國際通用量化漏洞嚴重程度的標準，分數介於 0.0 至 10.0 分。

嚴重等級 CVSS 分數區間 建議修補 SLA (時效) 典型漏洞範例
極危 (Critical) 9.0 - 10.0 24 - 48 小時內 未授權遠端執行程式碼 (RCE)、Log4j (CVE-2021-44228)
高危 (High) 7.0 - 8.9 7 天內 特權提升 (Privilege Escalation)、未授權 SQL 注入
中危 (Medium) 4.0 - 6.9 30 天內 跨站腳本攻擊 (XSS)、敏感資訊洩漏
低危 (Low) 0.1 - 3.9 排入常態版更計畫 系統版本 Banner 洩露、無直接危害之設定缺陷

A01 權限控制失效 (Broken Access Control)

使用者能夠存取未獲授權的資源，如一般帳號存取 `/admin` 或變更他人訂單資料。

A03:2021

A03 注入攻擊 (Injection - SQLi / Command)

攻擊者輸入惡意 SQL 指令或作業系統命令，繞過檢查並控制後端資料庫或伺服器。

A10:2021

A10 伺服端請求偽造 (SSRF)

誘使伺服器向內部網路發起未授權的 HTTP 請求，從而繞過外部防火牆阻擋。

防禦檢測手段比較 (弱掃 vs 滲透測試 vs 紅藍軍)

評估手段 運作機制與特點 執行頻率與成本 主要產出成果
弱點掃描 (Scan) 自動化工具比對已知 CVE 漏洞庫，不進行實際攻擊破壞。 高頻率（月/季）、低成本 已知漏洞清單與 CVSS 修補建議
滲透測試 (PenTest) 白帽駭客人工模擬真實攻擊，驗證漏洞能否組合並成功被 Exploited。 定期（年）、中高成本 入侵路徑圖解與概念驗證 (PoC) 報告
紅藍軍演練 (Red Team) 無預警下全方位模擬 APT 敵手，測試藍軍（SOC 團隊）的防禦與應變能力。 低頻率（1~2年）、高成本 企業 SOC 盲點與縱深防禦評估報告
