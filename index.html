資安漏洞 (Vulnerability) 與威脅 (Threat) 核心指南

涵蓋風險計算、CVSS 評分、OWASP Top 10 完整防護、MITRE ATT&CK 戰術與資安檢測比對。

漏洞 (Vulnerability) —— 防禦缺陷

定義：系統、軟體程式碼、網路協定、設定或管理流程中存在的**缺陷與弱點**。漏洞本身不會主動危害系統，但提供了威脅利用的管道。

常見形態：
• 未修補軟體漏洞（如 Log4j、Buffer Overflow）
• 安全設定不當（使用預設密碼、開放高風險 Port）
• 人員意識缺陷（未啟用 MFA、易受社交工程騙取帳密）

威脅 (Threat) —— 潛在破壞力

定義：任何可能利用漏洞對企業資產（資料、系統、業務運行）造成**傷害、破壞或中斷的潛在事件或行為者**。

常見形態：
• 人為意圖攻擊：黑客集團、APT 國家級網軍、惡意內部員工
• 惡意程式與手段：勒索軟體 (Ransomware)、DDoS 攻擊
• 環境與自然因素：地震、機房火災、電網中斷

CVSS 漏洞評分標準 (Common Vulnerability Scoring System)

CVSS 為量化漏洞嚴重程度的國際標準（分數範圍 0.0 至 10.0）：

嚴重等級 CVSS 分數區間 建議修補 SLA (時效) 典型漏洞範例
極危 (Critical) 9.0 - 10.0 24 - 48 小時內 未授權遠端程式碼執行 (RCE)、Log4j (CVE-2021-44228)
高危 (High) 7.0 - 8.9 7 天內 特權提升 (Privilege Escalation)、未授權 SQL 注入
中危 (Medium) 4.0 - 6.9 30 天內 跨站腳本攻擊 (XSS)、敏感資訊洩漏
低危 (Low) 0.1 - 3.9 排入常態版更計畫 系統版本 Banner 洩露、無直接危害之設定缺陷
Base Metrics (基本指標)

固有屬性評估

評估攻擊途徑 (Network/Local)、攻擊複雜度、所需權限及 CIA (機密性/完整性/可用性) 影響。

Temporal Metrics (時間指標)

隨時間演變因素

評估當前 Exploit 程式碼成熟度、官方是否已釋出修補檔 (Patch)。

Environmental Metrics (環境指標)

企業環境調整

依據漏洞設備是否處於內網隔離區或外網等實際環境修訂真實風險。

OWASP Top 10 核心 Web 漏洞庫 (全項解說)

全球最權威的應用程式安全漏洞風險統計：

A01:2021 - 權限控制失效 (Broken Access Control)

使用者能存取未授權資源，如一般帳號直接造訪 `/admin` 或修改他人訂單 ID。

A02:2021 - 加密機制失效 (Cryptographic Failures)

明文傳輸敏感資料或使用過時演算法（如 MD5、SHA1），導致資料遭側錄。

A03:2021 - 注入攻擊 (Injection)

輸入惡意 SQL 指令 (SQLi) 或 OS Command，繞過檢查並控制後端資料庫。

A04:2021 - 不安全設計 (Insecure Design)

架構缺乏威脅建模，例如業務邏輯缺陷導致未限制密碼嘗試次數。

A05:2021 - 安全設定缺陷 (Security Misconfiguration)

使用預設密碼、開啟不必要 Port 或雲端儲存桶 (S3) 設定為公開存取。

A06:2021 - 危險或過舊元件 (Vulnerable Components)

使用包含已知 CVE 漏洞的第三方函式庫，引發供應鏈漏洞風險。

A07:2021 - 認證及驗證失敗 (Authentication Failures)

缺乏 MFA、允許弱密碼或 Session 憑證傳輸暴露導致帳號遭撞庫破解。

A08:2021 - 軟體與資料完整性失敗 (Integrity Failures)

未驗證軟體更新檔簽章或 CI/CD 自動化管道遭插入惡意程式碼。

A09:2021 - 日誌記錄與監控失敗 (Logging Failures)

未記錄登入失敗或入侵跡象，導致入侵發生數月仍無法察覺與追溯。

A10:2021 - 伺服端請求偽造 (SSRF)

誘使伺服器向內部網路發送未授權 HTTP 請求，繞過外部防火牆。

防禦檢測手段比較 (弱掃 vs 滲透測試 vs 紅藍軍)

評估手段 運作機制與特點 執行頻率與成本 主要產出成果
弱點掃描 (Scan) 自動化工具比對已知 CVE 漏洞庫，不進行實際攻擊破壞。 高頻率（月/季）、低成本 已知漏洞清單與 CVSS 修補建議
滲透測試 (PenTest) 白帽駭客人工模擬真實攻擊，驗證漏洞能否被組合侵入。 定期（年）、中高成本 入侵路徑圖解與概念驗證 (PoC) 報告
紅藍軍演練 (Red Team) 無預警下全方位模擬敵手攻擊，測試 SOC 藍軍防禦與應變能力。 低頻率（1~2年）、高成本 企業 SOC 盲點與縱深防禦評估報告
